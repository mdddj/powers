# Kiro Powers 集合

为 Kiro IDE 精心策划的生产力增强 powers 集合。这些 powers 通过专业的工作流程、工具和最佳实践扩展了 Kiro 的能力。

## 📦 可用的 Powers

### 1. 🌐 网页文章提取器
**Power 名称:** `article-extractor`  
**GitHub 地址:** `https://github.com/mdddj/powers/tree/main/power-article-extractor`

从网页 URL 中提取干净、可读的内容，去除广告和杂乱信息。非常适合保存博客文章、教程和新闻。

**关键词:** 提取、下载文章、保存博客、抓取、去广告

**安装方法:**
```
1. 打开 Kiro IDE → Powers 面板
2. 点击 "Add power from GitHub"
3. 输入: https://github.com/mdddj/powers/tree/main/power-article-extractor
```

## 🚀 快速开始

### 安装 Power

1. 打开 Kiro IDE
2. 导航到 Powers 面板（点击 👻⚡ 图标）
3. 点击 "Add power from GitHub"
4. 粘贴上面的 GitHub URL
5. 点击 "Install"

### 激活 Power

- **自动激活:** 只需在对话中提及相关关键词，Kiro 会自动激活相应的 power
- **手动激活:** 直接输入 power 名称以强制激活

### 使用 Power

- 按照入门说明操作
- Power 会引导你完成其工作流程
- 享受增强的生产力！

## 💡 使用技巧

### 关键词触发

每个 power 都有特定的关键词。当你在对话中使用这些关键词时，Kiro 会自动加载相应的 power：

- 想要提取网页文章？说 "帮我提取这篇文章" 或 "下载这个博客"
- 需要头脑风暴？说 "我有个想法" 或 "帮我设计一下"
- 要生成更新日志？说 "生成 changelog" 或 "写发布说明"
- 需要写作帮助？说 "帮我写篇文章" 或 "起草博客"
- 想整理文件？说 "整理我的文件夹" 或 "清理下载目录"
- 开发 Flutter？说 "创建 Flutter 界面" 或 "设计移动端 UI"
- 做前端设计？说 "设计落地页" 或 "创建前端组件"
